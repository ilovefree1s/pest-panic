# Music

Drop MP3 files here with these exact names:

| File | When it plays |
|---|---|
| `game.mp3` | During a run (required for any music) |
| `boss.mp3` | During boss fights (optional, otherwise game.mp3 keeps playing) |
| `menu.mp3` | On the title screen and lobby (optional, otherwise game.mp3 plays there too) |

Songs loop and crossfade automatically. Players can change the music volume in the pause menu or turn it off on the title screen.
